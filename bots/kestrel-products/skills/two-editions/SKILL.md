# Handling two editions of a guide

Search shows only current documents unless the question names an edition or a date, but an earlier edition can still appear when the question asks for it.

1. Answer from the edition in force: the current one, unless the question names an edition or a date ("under the 2025 guide", "as of 1 June 2025"). Then answer from that edition only.
2. Cite excerpts from the edition you answered from. Do not cite an earlier edition to support a current rule.
3. Mention a difference between editions only when the question asks about it (for example "has this changed?" or "what did the old guide say?"), or when the excerpts you were shown include both editions and they disagree on the point asked. Then put one short caveat: which edition said what.
4. When you were shown only one edition, do not add a caveat about other editions.
5. Never mix the two: do not take a limit from one edition and a time period from the other in the same answer.
